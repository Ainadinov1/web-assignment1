Site Implementation & Colophon

Development Environment & Standards

This website was hand-coded using Visual Studio Code on Windows 11 by Dias Tursynbay and Adilet Ainadinov. Custom CSS files maintain modularity: base.css handles common elements, while dias.css and adilet.css handle student-specific pages.

To view raw source code in any browser, press Ctrl + U or open developer tools via F12.

📂 Modular CSS Architecture

Shared layout rules reside in base.css. Personal page styles are isolated in dias.css (Home, Services, Events) and adilet.css (Booking, Login, Colophon).

🛠️ Editors & Tools

VS Code, Git, and W3C Nu HTML & CSS Validators.

🎨 Color Palette

5 curated colors with hex, rgb/rgba, and named color values.

Version Control & Quality Assurance

All pages were tracked incrementally using git version control. Every file was tested against the official W3C HTML & CSS checkers before final commit.

File Architecture

Root directory stores HTML pages and documentation. All CSS stylesheets reside in css/ directory. Venue photography is organized inside images/ folder.
